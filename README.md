Форк для сборки прошивки Padawan для роутера TP-Link Archer C5 V4 с ROM 16MB.

Для сборки своей прошивки:
1. Создайте Fork этого репозитория;
2. Внесите нужные изменения в файл build.config;
3. Далее Actions=>Build firmware=>Run workflow;
4. Ждем завершения процесса, качаем;
5. После обновления прошивки рекомендуется сделать полный сброс настроек.

P.S.: В папке configs.build лежит дефолтный шаблон для сборки.
